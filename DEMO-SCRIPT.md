## Capture and accuracy notes

- No multiplayer or FPS gameplay segments. Preserve the clean right turn; brake before barriers. The closing scene is a panorama.
- Capture real companion responses. Do not mock output, type a fabricated answer into the interface, or present typed input as a microphone demonstration. Label any removed waiting time as a time cut.
- GPT-Live-1 is described as an optional capability; this cut demonstrates text input. A live voice exchange can replace that interaction only after it is actually recorded and verified.
- The Raffles before/after comes from `docs/evidence/raffles-refinement/`. Preserve original Google image attribution. Use the actual recorded session summary and diff; do not fabricate an agent conversation or represent the summary as a raw transcript.
- Describe the world-building as an Astra-assisted reference-review and refinement workflow. More locations are an extension of this process, not a demonstrated arbitrary-location generator or surveyed reconstruction.
- Use actual verification results for the recorded revision. The current repository has evolved since the earlier 200-test evidence record; do not overlay an unverified “latest” test count.
- Verify the selected recording environment and live companion behavior before capturing. The URL is from the project README; this script update does not itself verify deployment.
- The script intentionally focuses on the two submitted categories. New FPS, AI-pilot and Encik features are outside this cut, consistent with the user's earlier exclusions.
